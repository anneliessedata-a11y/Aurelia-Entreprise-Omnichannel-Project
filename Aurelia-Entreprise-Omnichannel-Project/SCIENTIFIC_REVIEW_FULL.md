# Aurelia Scientific Review — Full Portfolio

Each project defines a business question, target/objective, feature availability, validation strategy, metrics and limitations. Median-split targets are avoided. Temporal projects use chronological holdouts where appropriate. Project 3 is observational attribution, not causal incrementality. Project 11 predicts payment failure because no confirmed fraud label exists. Project 13 excludes neutral rating 3 from binary sentiment. Results are portfolio evidence on the supplied dataset, not production validation.
